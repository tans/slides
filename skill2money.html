技能从哪里加载：两类目录

以 Codex 为例，个人常用技能放用户目录，团队技能跟着项目走。

级别文件位置示例使用范围
用户级~/.agents/skills/laoluo/SKILL.md跨项目使用
项目级项目A/.agents/skills/laoluo/SKILL.md跟随项目共享
先读名称和描述

匹配任务后，再读取正文和所需资料。

技能装得越多，描述越占上下文，也越容易误触发。

不同 Agent 的目录与调用方式有所不同。含脚本的技能，安装前要检查来源与内容。

技能如何生效：上下文拼装

Agent 把规则、技能、记忆、历史消息和当前问题组织好，再交给模型。

技能说明放进消息

先提供名称和描述，
选中后再补充正文。

工具通过 tools 提供

模型发出调用请求，
Agent 执行后返回结果。

持续迭代：实际试用、修改说明，用 Git 记录变化，出问题时回滚。
